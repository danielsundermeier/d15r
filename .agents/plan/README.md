# Temporäre Arbeitsstände

Dieser Ordner enthält bei größeren Aufgaben den veränderlichen,
aufgabenspezifischen Arbeitsstand.

Arbeitsdateien:

- werden nur bei tatsächlichem Bedarf angelegt,
- wiederholen kein bestehendes Wissen aus `conventions/` oder `domains/`,
- werden nicht committed,
- werden nach vollständiger Verteilung des relevanten Wissens entfernt.

Diese Datei dokumentiert ausschließlich die Funktion des Ordners und bleibt
bestehen.
