# Identitätsbeobachtungen

Hier liegt die quellenbezogene Arbeitsschicht der Soul. Für ein relevantes
neues Identitätssignal entsteht bei Bedarf genau eine Datei
`YYYY-MM-DD-<gegenstand>.md`. Mehrere Werke aus demselben Ursprung werden in
dieser Datei als verbundene Quellenlinie behandelt.

Eine Datei enthält nur das gegenüber der kanonischen Soul relevante Neue:

```markdown
# Gegenstand

## Herkunft

## Neue Beobachtung

## Einordnung

Beobachtung | Interpretation | Hypothese | bestätigt

## Konsequenz für die Soul

Keine | präzisiert | ersetzt | entfernt | ergänzt
```

Bereits bekannte Aussagen werden nicht wiederholt. Diese Dateien werden nicht
standardmäßig geladen. Das aktuelle bestätigte Selbstverständnis steht
ausschließlich in `../AGENTS.md`.
